# Сохранённые исходники

Эти файлы скопированы по запросу автора. Это литературные/продуктовые источники для сравнения, **не файлы, которые нужно отправлять ученику вместо текущего промпта**. Внутренние ссылки в дословных копиях могут вести в закрытые источники и не требуют открытия для занятий.

| Файл | Фактический статус источника |
| --- | --- |
| THEO_COMPANION_APPROVED_v1.md | Утверждённый продукт v1.1, 12.10.2026; байты сохранены |
| NIKA_COMPANION_RELEASE_CANDIDATE_v1.md | Полная читательская версия; текущий реестр GPT_English называет её кандидатом, финальный APPROVED не найден; байты сохранены |
| THEO_DNA_SOURCE_2026-10-25.md | Дословный снимок действующей ДНК Тео, включая уточнения автора от 25 октября |
| GRAF_DNA_SOURCE_2026-10-25.md | Дословный снимок действующей ДНК Графа, включая уточнения автора от 25 октября |
| NIKA_CHARACTER_SOURCE_EXCERPT.md | Дословный раздел Nika актуальной CHARACTER_BIBLE; это явно обозначенный фрагмент, не полный файл |

Книжная резкость и драматургические привычки из ДНК не применяются к ученику автоматически. Учебные адаптации находятся в `profiles/`, качество обучения — в `src/`. Не переписывать эти снимки при улучшении продукта: получить новую исходную версию, зафиксировать её и явно обновить происхождение.

[Точные пути, ревизии, статусы и SHA-256](../provenance/SOURCES.json). Новая редакция не наследует статус APPROVED исходного продукта автоматически. Отдельное согласие на публичный перенос дано автором в текущем заказе.
